# ALEXIS vault starter

Copy this folder wherever you keep your Obsidian vault, open it in Obsidian, and set its path as `ALEXIS_VAULT` in `~/.claude/CLAUDE.md`. Claude Code reads and writes it as plain Markdown; no Obsidian plugin is needed.

| Folder | What goes there | Written by |
| --- | --- | --- |
| `0-Inbox` | Quick captures | You |
| `1-Projects` | One note per project: status, decisions, links | `/alexis:project close` |
| `2-Areas/Career/Impact.md` | One line per measurable result | `/alexis:project close` |
| `3-Ideas` | Business ideas with verdict and review date | `/alexis:project` (validation) |
| `4-Resources` | Reference material | You |
| `5-Archive` | Finished things | You |
